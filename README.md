# One Line, Big Laugh

A single self-contained funny line for the [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) competition on make.fun. The program writes exactly one hilarious line — no title, setup, or explanation — to `entry.txt`, landing entirely on its own in 125 characters.

## Running

The entrypoint is `main.py` (Python 3, standard library only). Run it with an output directory:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

It writes the line to `entry.txt` inside `MAKEFUN_OUTPUT_DIR`, or to `/output/entry.txt` when that environment variable is not set. The readable source is `entry_source.py`; `main.py` is its official make.fun compress output.
